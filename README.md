# PhysicsX Lab ⚛️

**An interactive physics learning platform designed for JEE aspirants.**

🌐 **Live Website:** https://physicsx-lab.streamlit.app/

## About

PhysicsX Lab is a Python-based educational web application designed to help students explore physics concepts, practise JEE-style questions, and evaluate their understanding through a test interface.

The project combines interactive simulations with question practice and assessment tools in one place.

## Features

### 🚀 Physics Simulator
- Explore projectile motion through interactive controls.
- Observe changes in the trajectory and related calculations.
- Visualise physics concepts through graphs.

### 🎯 JEE Practice
- Practise questions at different difficulty levels.
- Check answers and review hints or worked solutions.
- Track practice performance.
- Save and resume practice sessions.

### 📝 JEE Test
- Attempt a structured physics test.
- Navigate between questions.
- Work with a timer and JEE-style marking scheme.
- Review your performance and answers after submission.

## Tech Stack

- **Python** — application logic and calculations
- **Streamlit** — interactive web application
- **Matplotlib** — physics visualisations and graphs
- **JSON** — local practice-session data storage

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/PhysicsX.git
   ```

2. Open the project directory:

   ```bash
   cd PhysicsX
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   python -m streamlit run app.py
   ```
